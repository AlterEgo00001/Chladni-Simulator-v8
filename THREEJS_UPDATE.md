### 2. Синхронизация логики движения частиц
**Цель**: Обеспечить идентичное поведение частиц в GPU и CPU режимах

## 🔍 Ключевые исправления

### В `shaders/particle_compute.glsl`:

1. **Добавлена адаптивная частота**: `float actualAppliedFrequency`
2. **Адаптивное демпфирование для низких частот**:
   ```glsl
   if (actualAppliedFrequency < 300.0) {
       adaptDamp = min(0.97, damping + 0.03);
       forceMult = forceMultiplier * 1.25;
   }
   ```
3. **Использование адаптивного множителя силы**: `forceMult` вместо `forceMultiplier`

### В `chladni.js`:

1. **Передача частоты в GPU**: Добавлен `this.actualAppliedFrequency` в uniform переменные
2. **Синхронизация параметров**: Все параметры движения идентичны CPU версии
