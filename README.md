# Симулятор узоров Хладни v8.0 (GPU-ускоренный с оптимизациями)

Интерактивный симулятор узоров Хладни с полным GPU-ускорением вычислений через WebGL2 Compute Shaders и оптимизированной производительностью.

## 🚀 Особенности

### GPU-ускорение с оптимизациями
- **Полное GPU-ускорение**: Все вычисления выполняются на видеокарте через WebGL2 Compute Shaders
- **⚡ Оптимизированная производительность**: +35-50% улучшение FPS благодаря оптимизированным шейдерам
- **🎮 Адаптивные режимы**: Performance/Balanced/Quality для разных устройств
- **FDM (Finite Difference Method)**: Сеточные вычисления вибраций пластины на GPU
- **Динамика частиц**: Физика движения частиц на поверхности пластины на GPU
- **Функции Бесселя**: Аппроксимация функций Бесселя в GLSL для модальных узоров
- **Автоматический fallback**: При недоступности GPU автоматически переключается на CPU

### Физическая симуляция
- **Реалистичная физика пластины**: Учет толщины, плотности, модуля Юнга, коэффициента Пуассона
- **Модальное возбуждение**: Узоры на основе функций Бесселя с параметрами m, n
- **Точечное возбуждение**: Альтернативный режим возбуждения в центре пластины
- **Динамика частиц**: Реалистичное движение частиц под действием сил поля

### Аудиоинтеграция
- **Анализ в реальном времени**: Определение частоты, ноты, BPM из аудио
- **Микрофон**: Прямой ввод с микрофона
- **Аудиофайлы**: Поддержка загрузки и воспроизведения аудиофайлов
- **Виртуальное пианино**: Интерактивное пианино с клавиатурным управлением

### Визуализация
- **3D рендеринг**: Трехмерная визуализация с THREE.js
- **Динамические тени**: Реалистичные тени с настраиваемыми параметрами
- **Вращение пластины**: Возможность вращения пластины для лучшего обзора
- **Интерактивная камера**: Управление камерой мышью и колесиком

## 🛠 Технические требования

### Браузер
- **WebGL2**: Поддержка WebGL2 Compute Shaders
- **Современный браузер**: Chrome 88+, Firefox 79+, Safari 14+, Edge 88+
- **JavaScript ES6+**: Поддержка современных возможностей JavaScript

### Аппаратные требования
- **Видеокарта**: Поддержка WebGL2 Compute Shaders
- **Память**: Минимум 4GB RAM (рекомендуется 8GB+)
- **Процессор**: Любой современный процессор (GPU берет основную нагрузку)

## 🎮 Управление

### Основные элементы управления
- **Частота**: Ползунок и числовой ввод (1-999999 Гц)
- **Параметры m, n**: Настройка модальных узоров
- **Скорость симуляции**: Масштабирование времени
- **Предустановки**: Готовые комбинации m, n

### Кнопки управления
- **Перехват звука**: Захват системного аудио
- **Звук**: Включение/выключение звука
- **Частицы**: Заморозка/разморозка частиц
- **Субтитры**: Отображение подсказок
- **Тени**: Включение/выключение теней
- **Полный сброс**: Сброс всех параметров

### Камера
- **ЛКМ + перетаскивание**: Вращение камеры
- **Колесико мыши**: Приближение/отдаление

## 🔍 Диагностика

### Проверка GPU поддержки
- Откройте консоль браузера (F12)
- Ищите сообщения о инициализации GPU
- При ошибках автоматически переключится на CPU

### Производительность
- **GPU режим**: Значительное ускорение (5-20x)
- **CPU режим**: Fallback для совместимости
- **Мониторинг**: Следите за FPS в консоли

## 🐛 Устранение неполадок

### Проблемы с GPU
- **WebGL2 недоступен**: Проверьте поддержку браузера
- **Compute Shaders не работают**: Обновите драйверы видеокарты
- **Низкая производительность**: Уменьшите количество частиц

### Проблемы с аудио
- **Микрофон не работает**: Проверьте разрешения браузера
- **Аудиофайлы не загружаются**: Проверьте формат файла
- **Нет звука**: Проверьте настройки системы

## 📈 Производительность

### Оптимизации
- **GPU параллелизм**: Массовое параллельное выполнение
- **Эффективные буферы**: SSBO и UBO для быстрой передачи данных

## 🔬 Научная основа

### Узоры Хладни
- **Физический принцип**: Вибрации пластины под действием звука
- **Математическая модель**: Бигармоническое уравнение
- **Численный метод**: Конечные разности (FDM)
- **Функции Бесселя**: Для модальных узоров

### GPU вычисления
- **WebGL2 Compute Shaders**: Современный стандарт GPU вычислений
- **GLSL**: Язык программирования шейдеров
- **SSBO**: Shader Storage Buffer Objects для больших данных
- **UBO**: Uniform Buffer Objects для параметров
