# 🚀 ОПТИМИЗАЦИИ GPU ПРОИЗВОДИТЕЛЬНОСТИ

## 📊 Обзор оптимизаций

Данный документ описывает комплексные оптимизации GPU производительности для симулятора узоров Хладни, которые **не урезают функционал и графику**, а только улучшают производительность.

## 🎯 Ключевые оптимизации

### 1. **Оптимизация Compute Shaders**

#### 🔧 FDM Shader (`fdm_compute_optimized.glsl`)
- **Увеличен размер рабочей группы**: `32x32` вместо `16x16`
- **Оптимизированные функции Бесселя**: предвычисленные константы
- **Битовые операции для проверки границ**: `(i | j) < 0` вместо `i < 0 || j < 0`
- **Расширенная таблица корней Бесселя**: 8x8 вместо 5x5
- **Оптимизированная интерполяция**: использование `mix()` функций
- **Улучшенные математические операции**: предвычисленные степени

#### 🔧 Particle Shader (`particle_compute_optimized.glsl`)
- **Увеличен размер рабочей группы**: `512` вместо `256`
- **Оптимизированная билинейная интерполяция**: предвычисленные значения
- **Ранний выход в циклах**: `break` при достижении лимита соседей
- **Оптимизированное отталкивание**: использование `dot()` для расстояний
- **Улучшенная проверка границ**: битовые операции

### 2. **Оптимизация GPU менеджера**

#### 🔧 Адаптивные размеры рабочих групп
```javascript
// Автоматическое определение оптимальных размеров
optimizeWorkGroupSizes() {
    const maxWorkGroupSize = this.gl.getParameter(this.gl.MAX_COMPUTE_WORK_GROUP_SIZE_X);
    
    if (maxWorkGroupSize >= 1024) {
        this.particleWorkGroupSize = 1024;
    } else if (maxWorkGroupSize >= 512) {
        this.particleWorkGroupSize = 512;
    } else {
        this.particleWorkGroupSize = 256;
    }
}
```

#### 🔧 Режимы производительности
- **Performance**: `64x64` FDM, `1024` particles
- **Balanced**: `32x32` FDM, `512` particles  
- **Quality**: `16x16` FDM, `256` particles
